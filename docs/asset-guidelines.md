# Asset Guidelines

## Folder Structure

```txt
docs/concept-images/
  reference/   # user-provided or external visual references
  generated/   # Codex-generated concept art for this project

public/assets/
  creatures/   # runtime creature sprites, if added later
  ui/          # runtime UI images, icons, and backgrounds
```

## Naming Rules

- Use lowercase words separated by hyphens.
- Include role and version where useful.
- Use `reference` for source material and `concept` for generated or design-stage material.
- Runtime assets should name the subject directly, for example `creature-bubblit-id-m001.png`.

## Visual QA Rules

- Pixel art should stay crisp.
- Avoid blur filters on sprites.
- Stage colors must match across cards, labels, connection lines, and legends.
- Connection lines should not cover labels or important creature silhouettes.
- Check at mobile, tablet, and desktop widths.
