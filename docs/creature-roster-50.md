# 50 Original Pixel Creatures

This roster provides 50 original, brand-safe creatures for the first playable prototype. The user may call them digital monsters casually, but app copy and code should use **monsters**, **creatures**, or **pixel mons** rather than protected franchise language.

## Stage Distribution

- Baby: 6
- In-Training: 7
- Rookie: 9
- Champion: 9
- Ultimate: 7
- Mega: 6
- Special: 6
